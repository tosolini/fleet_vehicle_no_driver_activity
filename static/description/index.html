Fleet Vehicle - No Driver Activity

Remove the automatic "Specify the end date" TODO activity created when a vehicle driver changes.

Why

The companion module fleet_vehicle_history_date_end already closes the previous driver history automatically. The default TODO is redundant and adds noise.

Features

  • Prevents the default TODO activity when a new driver is assigned
  • Keeps all other fleet behaviors unchanged
  • Compatible with fleet_vehicle_history_date_end

Installation

  1. Dependencies: fleet, fleet_vehicle_history_date_end
  2. Update the Apps list and install the module
